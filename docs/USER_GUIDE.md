# User Guide

## Load Data

Open **Upload**, drop CSV, TSV, Excel, or JSON files, review detected columns, rename columns if needed, then confirm import. Built-in sample datasets are available on the same page.

## Explore

Use **Summary Stats**, **Charts**, **Correlation**, and **Frequency** to inspect data. Use the top dataset selector to switch between recently loaded datasets.

## Clean And Transform

Use **Clean & Transform** for formula-style column creation and **Stats Workbench** for guided transforms, variable views, quality checks, and analysis recommendations.

## Analyze

Use **Inference Tests**, **Regression**, **Advanced Analysis**, **Distributions**, and **Stat Modules** for statistical workflows.

## Export

Open **Export & Reports** to download data, reports, and reproducible starter scripts. All exports are generated locally.
