# Ten enhancements for other studios

Implemented across the 16 statistics studios other than ANOVA, their 137 labs, and the Distributions Studio's 32 models:

1. Search lab names and method concepts inside each studio.
2. Filter introductory, core, and advanced methods.
3. Favorite labs and show only favorites.
4. Explicit completion controls and a studio progress bar.
5. Continue learning from the last selected unfinished method, then the next unfinished method.
6. Save up to 3,000 characters of notes for each lab separately.
7. Review each method's actual inputs, interpretation, and limits with a three-item readiness checklist.
8. Answer an interpretation quiz with explanations authored for methods in that same studio.
9. Practice input, calculation, and assumption flashcards specific to the selected method.
10. Export and import portable JSON containing favorites, progress, notes, readiness, and quiz completion; validate studio identity and file contents before applying an import.

The learning workspace is available on studio landing pages and below individual lab screens. Progress stays isolated by studio and lab in browser storage. ANOVA retains its existing learning features. Calculators and datasets remain independent from these learning-progress records.
